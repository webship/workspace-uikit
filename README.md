# @webship.co/workspace-uikit

UIkit for the [Webship Workspace](https://github.com/webship/workspace) dashboard: a builder that serves the components
demo site of the UIkit step pack in a container, the step pack wired into the workspace's testing setup of that site
and of any project whose theme is built on UIkit, and its AI items.

The builder, the tests and CI come with the first release, `1.0.0`.
